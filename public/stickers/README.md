# Стикеры чата

Иллюстрированные стикеры из официального репозитория [WhatsApp/stickers](https://github.com/WhatsApp/stickers) (примеры для разработчиков стикер-паков).

- **cuppy** — персонаж Cuppy (чашка кофе)
- **together** — набор «Together While Apart» (ВОЗ)

Обновление файлов:

```bash
bash /home/crm-frontend/scripts/download-stickers.sh
```
